## 用途

前端开发联调时，总是要临时起一个 Postman。API 调试台把常用接口、环境变量和鉴权头都固化下来，浏览器打开就能用。

## 功能

- 接口集合存储在本地，随时增删改
- 多环境切换（开发 / 测试 / 生产），变量集中管理
- 请求历史记录，支持一键重放
- 响应支持格式化、搜索与高亮
